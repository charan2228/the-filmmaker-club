# The Filmmaker Club

A cinematic movie-screening ticket booking website prototype.

## Current prototype
- Responsive event landing page
- Movie/date/time/venue/price/capacity configuration in `app.js`
- Booking modal
- Browser-side seat count
- Confirmation ticket UI

## Production upgrades needed
This static prototype should be connected to a real backend before accepting paid bookings:
1. Database for events, bookings and waitlist
2. Server-side capacity enforcement
3. Payment gateway
4. Secure unique QR ticket generation
5. Admin authentication/dashboard
6. QR check-in endpoint with one-time validation
7. Email/WhatsApp confirmation
8. Deployment environment variables and production hosting
